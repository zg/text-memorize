# Contributing

Contributions are welcome.

1. Fork the repository and create a branch from `main`.
2. Make your change, with tests where it changes behavior.
3. Run the tests: `python3 -m unittest discover tests`
4. Open a pull request describing what changed and why.

The code targets Python 3 and has no third-party dependencies; please keep it that
way. CI runs the tests on Linux, macOS and Windows, so avoid platform-specific
behavior.

Use the issue templates to report bugs or propose features.
